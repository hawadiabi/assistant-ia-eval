# Conditionnel présent

Formation : on prend le radical du futur simple et on ajoute les terminaisons de l'imparfait : -ais, -ais, -ait, -ions, -iez, -aient.

Exemples :
- chanter : je chanterais, tu chanterais, il chanterait, nous chanterions, vous chanteriez, ils chanteraient
- finir : je finirais
- aller : j'irais
- être : je serais
- avoir : j'aurais
- faire : je ferais
- venir : je viendrais

Emplois :
- L'hypothèse : Si j'avais le temps, je voyagerais.
- La politesse : Pourriez-vous m'aider ?
- Le souhait : J'aimerais partir en vacances.

Pièges :
- Je chanterai (futur, terminaison -ai) et je chanterais (conditionnel, terminaison -ais) ne s'écrivent pas pareil.
- Après si exprimant une condition, on n'emploie jamais le conditionnel : on écrit Si j'avais, et non Si j'aurais.

# Accord du participe passé des verbes pronominaux

Les verbes pronominaux se conjuguent avec être, mais l'accord ne se fait pas toujours avec le sujet.

Règle générale : le participe passé s'accorde avec le complément d'objet direct (COD) si celui-ci est placé avant le verbe. Souvent, le COD est le pronom se.
- Elle s'est lavée. (se est le COD, placé avant : accord)
- Elle s'est lavé les mains. (le COD est les mains, placé après : pas d'accord)
- Les lettres qu'ils se sont écrites. (le COD que est placé avant : accord)

Verbes essentiellement pronominaux (qui n'existent qu'à la forme pronominale) : le participe s'accorde avec le sujet.
- Elle s'est évanouie.
- Ils se sont souvenus.
- Elles se sont absentées.

Participe toujours invariable : quand le pronom est un complément indirect (on peut dire à elle, à eux).
- Elles se sont parlé.
- Ils se sont plu.
- Elles se sont souri.
- Ils se sont téléphoné.
- Elle s'est rendu compte de son erreur.

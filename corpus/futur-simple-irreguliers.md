# Futur simple des verbes irréguliers

Règle : les terminaisons sont toujours les mêmes (-ai, -as, -a, -ons, -ez, -ont), mais le radical change. Le futur se termine toujours par -r- avant la terminaison.

Verbes à connaître :
- aller : j'irai, tu iras, il ira, nous irons, vous irez, ils iront
- être : je serai, tu seras, il sera, nous serons, vous serez, ils seront
- avoir : j'aurai, tu auras, il aura, nous aurons, vous aurez, ils auront
- faire : je ferai
- venir : je viendrai
- voir : je verrai
- pouvoir : je pourrai
- vouloir : je voudrai
- savoir : je saurai
- devoir : je devrai
- envoyer : j'enverrai

Attention : je vais, tu vas, il va sont le présent du verbe aller, pas le futur simple.

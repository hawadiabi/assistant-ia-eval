# Accord du participe passé employé avec avoir

Règle : le participe passé s'accorde en genre et en nombre avec le complément d'objet direct (COD), seulement si le COD est placé avant le verbe. Sinon, il reste invariable.

Exemples :
- J'ai mangé les pommes. Le COD est après le verbe, donc pas d'accord.
- Les pommes que j'ai mangées étaient bonnes. Le COD "que" (les pommes) est avant le verbe, donc accord au féminin pluriel.
- Je les ai vues. Le COD "les" est avant le verbe, donc accord.

Cas sans accord :
- Quand le verbe n'a pas de COD : Elles ont parlé.
- Quand le COD est après le verbe : Elle a écrit une lettre.

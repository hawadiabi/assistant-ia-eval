# Futur antérieur

Formation : l'auxiliaire avoir ou être au futur simple, suivi du participe passé.

Exemples :
- chanter : j'aurai chanté, tu auras chanté, il aura chanté, nous aurons chanté, vous aurez chanté, ils auront chanté
- aller : je serai allé(e), tu seras allé(e), il sera allé, nous serons allés, vous serez allés, ils seront allés
- finir : j'aurai fini

Emplois :
- Une action terminée avant une autre action future : Quand il aura fini, nous partirons.
- Une supposition sur le passé : Il aura oublié notre rendez-vous.

Règles d'accord : les mêmes que pour le passé composé.

# Plus-que-parfait de l'indicatif

Formation : l'auxiliaire avoir ou être à l'imparfait, suivi du participe passé.

Exemples :
- chanter : j'avais chanté, tu avais chanté, il avait chanté, nous avions chanté, vous aviez chanté, ils avaient chanté
- aller : j'étais allé(e), tu étais allé(e), il était allé, nous étions allés, vous étiez allés, ils étaient allés
- finir : j'avais fini

Emploi : il exprime une action passée antérieure à une autre action passée.
- Quand je suis arrivé, le film avait déjà commencé.

Règles d'accord : les mêmes que pour le passé composé. Avec être, le participe s'accorde avec le sujet. Avec avoir, il s'accorde avec le COD placé avant le verbe.
- Les fleurs qu'il avait cueillies étaient belles.
- Elles étaient parties tôt.

# Passé composé avec l'auxiliaire être

Formation : l'auxiliaire être au présent, suivi du participe passé.

Se conjuguent avec être :
- Une série de verbes de mouvement ou de changement d'état : aller, venir, arriver, partir, entrer, sortir, monter, descendre, naître, mourir, rester, tomber, devenir, retourner.
- Tous les verbes pronominaux : se laver, se lever, s'asseoir.

Exemples :
- aller : je suis allé(e), tu es allé(e), il est allé, nous sommes allés, vous êtes allés, ils sont allés
- partir : elle est partie
- se lever : je me suis levé(e)

Piège : monter, descendre, sortir, entrer, rentrer, retourner et passer se conjuguent avec avoir quand ils ont un complément d'objet direct.
- Elle est montée au deuxième étage.
- Elle a monté les valises.

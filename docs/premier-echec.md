# Premier échec observé

Date : 12 novembre 2026
Modèle : llama3.1:8b (Ollama, local)

Question : Conjugue le verbe aller au futur simple.

Réponse du modèle : je vais, tu vas, il va, nous allons, vous allez, ils vont.

Problème : c'est le présent de l'indicatif, pas le futur simple.

Réponse attendue : j'irai, tu iras, il ira, nous irons, vous irez, ils iront.
